# Autonomous_Navigation
Autonomous Navigation Robot is a ROS2-based project focused on enabling a four-wheel robot to navigate autonomously in an indoor environment. The system uses an RPLIDAR A1 for environment sensing and mapping, wheel encoders, and Cartographer SLAM for creating the map. AMCL is used for localization, while Nav2 handles path planning and navigation to the given goal. The robot receives velocity commands through ROS2 and controls the motors using an Arduino Mega2526. The project combines sensor data, localization, odometry, and navigation to allow the robot to move from its current position to a selected goal while avoiding obstacles.
